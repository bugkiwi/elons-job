这份政策说明 Elon 的工作如何处理 X 评论与帖子正文、TypeSafe API Key、本地缓存与统计信息。扩展只为提供评论过滤和帖子 SLOP 标记而处理必要数据。

一句话说明

扩展会把 X 帖子正文，或 Tweet Detail 回复中的用户名和评论正文发送给 TypeSafe，用于内容分类；我们不建立开发者后端，不出售数据，也不用于广告画像。

适用范围

本政策适用于 Chrome 扩展“Elon 的工作”（以下简称“扩展”）及其在 X（x.com）页面中的评论过滤和帖子 SLOP 标记功能。

扩展处理当前页面可见的帖子正文，并在 Tweet Detail 页面处理回复；不读取私信。扩展开发者不是 X 或 TypeSafe 的官方代表。

处理哪些数据

X 帖子正文、用户名与评论正文从当前页面帖子或 Tweet Detail 回复中读取，用于生成 SLOP 标记或评论过滤判定；正文可能包含 emoji、标点和必要的结构信号。
TypeSafe API Key由用户主动输入，保存在当前浏览器的本地存储中，仅用于向 TypeSafe 发起鉴权请求。
本地配置与统计包括启用状态、规则、阈值、检查数量、隐藏数量和请求数量，用于维持扩展设置与界面显示。
临时分类缓存扩展使用浏览器会话存储缓存重复评论的分类结果，缓存 key 使用内容和规则的 hash，不保存评论原文。

不会收集的内容

扩展不会读取或收集浏览历史、Cookie、X 登录凭证、私信、图片、视频或头像内容，也不会建立用户画像。

如何使用数据

  • 将帖子正文，或用户名和评论正文发送给 TypeSafe，获取 SLOP、色情、性暗示、色情引流和 spam 规则的概率结果。
  • 在本地结合识别规范、过滤阈值和页面结构信号决定是否隐藏评论或叠加 SLOP 标记。
  • 使用本地配置、统计和临时缓存，减少重复请求并控制 API 成本。

数据不会用于个性化广告、出售、与无关第三方共享或训练开发者自己的用户画像。

如何共享数据

为完成评论或帖子分类，相关内容会通过 HTTPS 发送至 TypeSafe API。TypeSafe 对收到的数据的处理、保留和删除受其自身服务条款与隐私政策约束；建议用户同时阅读 TypeSafe 的相关政策。

扩展开发者不运营用于接收这些内容的服务器，也不会人工查看内容。除 TypeSafe 这一提供分类服务的必要服务商外，扩展不会向其他第三方共享这些内容。

API Key 不会发送给扩展开发者；它只在浏览器本地保存，并作为请求凭证发送给 TypeSafe。

安全与保留

  • 扩展使用 HTTPS 与 TypeSafe 通信。
  • API Key 由 service worker 读取，不写入 X 页面 DOM、URL 或调试日志。
  • 用户可以在设置中心更换或删除 API Key，并清空本地分类缓存。
  • 卸载扩展会移除其浏览器本地存储；TypeSafe 侧的数据保留由 TypeSafe 的政策决定。

任何网络错误、API 超时、鉴权失败或配额耗尽时，扩展会保持评论显示、帖子正文不变，不会在不确定时隐藏或标记内容。

你的控制权

你可以随时暂停保护、关闭单项规则、修改评论或帖子阈值、修改识别规范、关闭评论/帖子检查按钮、删除 API Key 或清除本地缓存。扩展只改变本地页面显示，不删除或修改 X 上的原评论和帖子。

首次输入 API Key 前，请确认你理解并同意：可见帖子正文，或评论用户名和正文会被发送给 TypeSafe 进行分类。

联系与政策更新

如果你对数据处理有疑问或希望报告问题，可以通过项目的 GitHub Issues 联系维护者。

如果扩展的数据处理方式发生变化，我们会更新本页面的生效日期，并在扩展界面中提供相应提示。继续使用更新后的扩展即表示你已阅读最新政策。

本扩展的数据使用遵循 Chrome Web Store User Data Policy 及 Limited Use 要求：数据只用于提供评论过滤和帖子 SLOP 标记这一单一用户功能，不用于广告或无关用途。
